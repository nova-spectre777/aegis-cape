# Architecture

- `engine-cpp`: high-performance CAPE-Σ reference solver and outcome-envelope construction.
- `coordinator-go`: simulator quorum coordination, policy hashing, and HTTP assessment API.
- `adversary-python`: deterministic hostile-world generation and benchmark research.
- `wallet-ts`: browser/wallet-side policy and assessment SDK.
- `contracts-solidity`: source-level smart-account/outcome commitment research.
- `research-rust`, `research-zig`, `proofs-lean`: future verified/portable engines.

No component requires or stores a seed phrase or private key.
